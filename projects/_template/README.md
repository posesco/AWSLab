# Lab README Template

Use this template as the manually maintained preamble for each Terraform lab README. `scripts/tf-docs.sh` preserves everything before `## Requirements`, then refreshes the generated Terraform reference and appends a graph diagram. Safe rerun note: the script currently appends a new `## Diagram` section on every run, so remove duplicate diagram sections before committing regenerated docs.

## Commands

```bash
cd projects/<lab_name>
terraform init
terraform workspace select dev || terraform workspace new dev
terraform fmt -check
terraform validate
terraform plan -out=tfplan
terraform apply tfplan
terraform destroy
```

## Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Foundation reuse | Use existing remote state and `modules/common-tags`. | Keeps labs aligned with the repo architecture and tagging contract. |
| Lifecycle | Disposable by default. | Prevents cost drift and supports repeatable study sessions. |
